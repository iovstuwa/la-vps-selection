## 常见问题

### 美国 VPS 推荐选洛杉矶还是纽约？

取决于访问者位置和网络需求。面向美国西海岸或亚洲方向用户时，可以优先比较洛杉矶节点；面向美国东部用户，则应把东部机房纳入候选。距离只是参考，实际路线和运营商连接也会影响结果。

### Basic 和 E-Commerce 的区别是什么？

官方将 Basic 定位为较经济的 VPS，并说明部分地点提供本地互联或较经济的中国连接；E-Commerce 则强调多数地点具备 premium China connectivity。洛杉矶 E-Commerce 页面还列出了具体网络互联信息。应按对应地点的产品页面核对，不要仅凭套餐名称推断实际性能。

### 页面价格是不是都按月计费？

不是。官方页面对不同配置展示了月、季度、半年和年等周期；部分低配价格明确标为季度或半年，也有个别价格在页面摘录中没有显示周期。购买前请确认购物车里的计费周期、首期金额和后续续费金额。

### E-Commerce+SLA 是否一定比普通方案快？

不能这样下结论。SLA 页面提供了网络配置与服务等级信息，但它不等于对每个用户的实际延迟、下载速度或应用性能作保证。若速度是核心需求，应该结合目标网络的测试结果、业务架构和时段表现来选择。
